# Todo-List
This is my first project after learning JS.

## About
A simple TodoList built with HTML,CSS, and JavaScript.
Create,complete,filter, and delete tasks, with support for a dark/light theme and using LocalStorage for save data.
## Features
- Add new todo with a modal window
- Mark todo as complete
- Delete todo
- Filter todos by status (All/ Complete/ Not Complete)
- Toggle between dark and light themes
- save data to LocalStorage
- load data from LocalStorage

- HTML5
